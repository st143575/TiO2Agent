# 抽取标准答案（extraction gold）

每篇专利一个 JSON（文件名是公开号），记录"从原文应当抽出哪些事实"。用途：对比规则抽取、大模型抽取、二者结合的效果。

| CN115466527A.json | 一种过滤性好的腈纶化纤用钛白粉及其生产方法 | 123 | draft |
| CN114573021A.json | 一种高纯度混晶型钛白粉及其生产方法 | 58 | draft |

CN116694108A 的人工核对结果目前在 `tests/fixtures/CN116694108A.facts.expected.json`（规则抽取器的逐行核对快照，不含证据原文），还没有转成本格式。

## 标注原则

1. **只看原文**：照着 PDF 的文字和图片标注，不参考任何抽取器的输出。
2. **每条有出处**：`evidence` 是原文的连续片段（去掉空白后必须是所引权利要求或段落的子串），`where` 指明位置；标注的每个数字都必须出现在 `evidence` 里。
3. **原文有错照录**：错字、缺用量、前后不一致都不修正，写进 `issue`（单条）或 `notes`（整篇）。缺失的用量**不补**（例如腈纶实施例2没写沉淀剂用量，就没有这条事实）。
4. **状态**：`draft` 表示待人工审阅；审阅确认后改为 `reviewed`。

## 范围

| 纳入 | 不纳入 |
|---|---|
| 权利要求（全部） | 发明内容/有益效果里逐字复述权利要求的段落 |
| 实施例段落（`scope.paragraphs` 逐个列出） | 对比实验/对比案例的文字（测试安排，不是配方） |
| 检测结果表（多为图片，标 `requires_ocr`） | 对结果表的文字总结 |

被排除的段落及理由列在每个文件的 `excluded` 里。

## 字段

```json
{
  "id": "F001",
  "kind": "component | parameter | option | result",
  "subject": "claim:1 | E1 | 市场上钛白粉",
  "step": "S2 | null",
  "name": "去离子水",
  "qualifier": "加入锆盐后 | null",
  "low": 30, "high": 50, "unit": "份",
  "options": ["…"],
  "text": ">92 | 较好",
  "evidence": "去离子水30-50份",
  "where": {"claim": 1} | {"paragraph": "0027"} | {"figure": "图2", "page": 7},
  "requires_ocr": true,
  "issue": "…"
}
```

- **subject**：权利要求写 `claim:N`；实施例写 `E1/E2/E3`（按出现顺序，与结构识别一致）；结果表里的对照样品用表头原文（如“市场上钛白粉”）。
- **step**：统一写 `S1…`（原文“S1、”和“步骤1：”都记为 `S1`）。权利要求里“所述步骤4中…”这类引用也按所指步骤填写；实施例中写在步骤之前的组成为 `null`。
- **name**：用原文用词，不做同义词归并（“锐钛型二氧化钛”不写成“二氧化钛”，“磷酸含量”与“含磷量”各按原文）。工艺参数用固定名称：温度、转速、搅拌时间、静置时间、反应时间、熟化时间、空压时间、煅烧温度、加入时间、料浆浓度、pH。
- **qualifier**：只在同一主体、同一步骤出现同名参数时用来区分（如腈纶 S3 两次调 pH：`加入锆盐后`/`加入铝盐后`；`加入时间` 的限定是加入的物料）。
- **值**：范围填 `low`/`high`；单个值 `low == high`；单边界（`>92`）只填一侧并把原样写进 `text`；非数值结果只填 `text`。
- **unit**：份、%、℃、rpm、min、h、g/L、μm；pH 无单位。原文的“转/分钟”“r/min”记 rpm，“分钟”记 min，“小时”记 h，全角“％”记 %。

## 校验

```bash
uv run pytest tests/test_extraction_gold.py        # 证据、数字、覆盖、步骤、唯一性
uv run python evals/render_gold_review.py          # 生成审阅表 REVIEW.md
```

`test_every_number_in_scope_is_labelled` 会把范围内每个权利要求和实施例段落里的数字（除去“S2”“步骤1”“权利要求1-4”这类引用）与已标注的数字比对，用来发现漏标。图片里的结果无法与文字层比对，需要对照图片目视审阅。
